КОМАНДА ПЕРВЫХ — приложение для телефона (PWA)
==============================================

Что в папке
  index.html             — само приложение
  manifest.webmanifest   — название, иконка, цвета (нужно для установки на телефон)
  sw.js                  — работа без интернета
  icons/                 — иконки приложения
Все файлы и папку icons нужно выкладывать вместе, не меняя названий.

ВАРИАНТ А. GitHub Pages — бесплатно, ссылка постоянная (рекомендую)
  1. Зарегистрируйтесь на github.com (нужна только почта).
  2. Справа вверху «+» → «New repository». Имя: komanda-app. Тип: Public. Нажмите «Create repository».
  3. На странице репозитория нажмите ссылку «uploading an existing file».
  4. Перетащите в окно ВСЕ файлы из этой папки вместе с папкой icons. Внизу — «Commit changes».
  5. Откройте вкладку «Settings» → слева «Pages».
     В «Branch» выберите «main» и папку «/ (root)» → «Save».
  6. Через 1–2 минуты вверху этой страницы появится ссылка вида
       https://ВАШ-ЛОГИН.github.io/komanda-app/
     Это и есть адрес приложения.

ВАРИАНТ Б. Netlify — ещё проще
  1. Зарегистрируйтесь на app.netlify.com.
  2. Откройте app.netlify.com/drop и перетащите туда ВСЮ папку komanda-app.
  3. Получите ссылку вида https://что-то.netlify.app (в настройках можно переименовать).

ВАРИАНТ В. Свой адрес клуба (например app.komanda.fit)
  Передайте эту папку тому, кто обслуживает сайт или сервер клуба: файлы просто кладутся
  в папку сайта. Важно: адрес должен открываться по https — без этого установка не работает.

Как установить на телефон
  iPhone:  откройте ссылку в Safari → «Поделиться» (квадрат со стрелкой) → «На экран «Домой»».
  Android: откройте ссылку в Chrome → меню ⋮ → «Установить приложение»
           (или кнопка «Установить на телефон» прямо в приложении).

Как обновлять
  1. Замените index.html новым (в GitHub: открыть файл → значок карандаша, или «Add file → Upload files»).
  2. В файле sw.js поменяйте VERSION = 'kp-v1' на 'kp-v2' (потом kp-v3 и т. д.).
  У пользователей обновление подтянется при следующем открытии приложения.

Важно
  Это демо-версия: данные вымышленные, платежи не проводятся. Прогресс каждого
  пользователя хранится только на его телефоне. Настоящие данные появятся после
  подключения к CRM клуба.
